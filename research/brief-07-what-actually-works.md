# Research Brief 07: What Actually Works in Conflict Monitoring Dashboards

## Objective
Research REAL, WORKING conflict monitoring and OSINT dashboards. Not concepts — actual deployed systems. What tech do they use? What made them succeed? What features do users actually care about? We need to build something that WORKS, not a demo that looks pretty.

## Research Areas

### 1. Real Working OSINT/Conflict Platforms
- Liveuamap — how does it work? Tech stack? What makes it effective?
- ACLED dashboard — their actual visualization approach
- HDX (Humanitarian Data Exchange) — OCHA's platform
- Crisis24 / GardaWorld intelligence dashboards
- Bellingcat's investigation tools and methods
- OSINT Framework — what tools are actually used daily?
- What open-source OSINT tools have active communities?

### 2. Features That Users Actually Need
- What do intelligence analysts actually look at daily?
- Which dashboard features get used vs which are "nice to have" that nobody clicks?
- Alert fatigue — how do working platforms avoid it?
- Map vs feed vs timeline — which view do analysts spend most time in?
- Search and filtering — what patterns work?
- Mobile access requirements — do analysts use dashboards on mobile?

### 3. MVP Features for a Working Dashboard
- What is the absolute minimum to be USEFUL (not just a demo)?
- What can be cut without losing core value?
- How long does it take to go from zero to useful dashboard?
- What existing platforms did right in their first version

### 4. Common Pitfalls and Time Wasters
- Overengineering data pipelines before having users
- Building NLP features nobody asked for
- Spending months on a map that could be done with Mapbox in a day
- Trying to monitor too many sources at once
- Building alerting before having reliable data flow
- Features that sound cool but add no analytical value

### 5. Data Quality Reality Check
- How reliable are free conflict data APIs really?
- Which RSS feeds actually update consistently?
- How much data cleaning is needed in practice?
- What sources have the best signal-to-noise ratio?
